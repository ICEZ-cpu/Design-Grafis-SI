Modul Desain Grafis

CorelDRAW Dasar (Bab 1 – 7)

Penjelasan simpel, praktis, dan dilengkapi kuis interaktif.

Ringkasan Materi per Bab

CorelDRAW adalah program desain grafis vektor populer untuk menggambar, menyunting, dan menulis.

  • Area Kerja Utama: Title Bar, Menu Bar, ToolBar, Property Bar (pengaturan alat aktif), Ruler (penggaris), Drawing Window, Drawing Page (kertas kerja), FlyOut, dan Color Palette.
  • Rectangle Tool (Kotak):
    • Tahan Ctrl = membuat bujur sangkar (persegi sama sisi).
    • Tahan Shift = menggambar dari titik tengah.
    • Tahan Ctrl + Shift = persegi sama sisi dari titik tengah.
  • Ellipse Tool (Lingkaran): Untuk membuat elips, lingkaran sempurna (tahan Shift/Ctrl), Arc (busur), dan Pie (potongan kue).
  • Color Palette: Klik Kiri untuk warna isi (Fill), Klik Kanan untuk warna garis tepi (Outline).
  • Polygon & Star Tool: Untuk membuat segi banyak dan bintang. Di Property Bar kita bisa mengatur Number of points (jumlah sudut) dan Sharpness (ketajaman sudut bintang, aktif jika titik > 7).
  • Spiral Tool: Membuat garis melingkar. Ada 2 jenis:
    • Symmetrical Spiral: Jarak antar putaran sama rata.
    • Logarithmic Spiral: Jarak putaran makin melebar ke luar.
  • Graph Paper Tool (Grid): Membuat kotak-kotak tabel/grid. Jumlah baris dan kolom diatur lewat Property Bar.

Menu: Arrange → Transformations memiliki 5 fungsi utama:

  • Position: Memindahkan objek secara presisi (koordinat X/Y atau posisi relatif).
  • Rotation: Memutar objek sesuai sudut derajat.
  • Scale: Mengubah skala ukuran (%) dan mencerminkan (mirror) objek.
  • Size: Mengubah ukuran objek dengan angka pasti.
  • Skew: Memiringkan objek secara horizontal atau vertikal.

Mengatur Tumpukan Objek (Arrange → Order):

  • To Front / To Back of Layer: Paling depan / paling belakang.
  • Forward One / Back One: Maju satu langkah / mundur satu langkah.

Garis Terbuka = ujung tidak bertemu (tidak bisa diisi warna Fill). Garis Tertutup = ujung bertemu (bisa diisi warna Fill).

  • Freehand Tool: Menggambar bebas seperti pensil.
  • 2-Point Line: Menggambar garis lurus dari titik awal ke akhir.
  • Bezier & Pen Tool: Menggambar garis lengkung/kurva presisi dengan titik-titik node.
  • Artistic Media: Membuat garis artistik seperti kaligrafi atau kuas.
  • B-Spline & 3-Point Curve: Membuat kurva lengkung yang halus dengan mudah.
  • Polyline: Menggambar garis bersambung/segi banyak (klik ganda untuk mengakhiri).
  • Smart Drawing: Mengubah coretan tangan kasar menjadi garis/bentuk yang rapi otomatis.

Agar bentuk dasar (seperti kotak/lingkaran) bisa diubah bebas, ubah dulu menjadi kurva lewat Arrange → Convert to Curve, lalu edit memakai Shape Tool.

  • Node: Titik hitam kecil di sepanjang garis objek.
  • Segment: Garis yang menghubungkan dua node.
  • 3 Tipe Node:
    • Cusp (Tajam): Kedua tuas kontrol bergerak bebas, cocok untuk sudut lancip.
    • Smooth (Halus): Tuas kontrol sejajar lurus, cocok untuk lengkungan mulus.
    • Symmetrical (Simetris): Tuas kontrol sejajar dan panjangnya sama persis.

Ada 2 jenis teks di CorelDRAW:

  • Artistic Text: Untuk teks pendek/judul. Mudah diberi efek (seperti Extrude atau melengkung mengikuti garis).
  • Paragraph Text: Untuk teks panjang (artikel/brosur), mendukung kolom, bullet, dan dropcap.

Fitur Penting: Text → Fit Text to Path digunakan untuk menempelkan teks agar mengikuti bentuk garis/kurva.

  • Outline Tool (F12): Mengatur ketebalan garis tepi, warna garis, dan pola garis (putus-putus atau lurus).
  • Fill Tool: Mengatur warna isi objek.
    • Interactive Fill (G): Memberi warna solid atau gradasi (perpaduan 2+ warna) secara langsung.
    • Smart Fill: Mewarnai area tertutup hasil perpotongan beberapa objek.
    • Mesh Fill (M): Gradasi warna kompleks menggunakan jaring-jaring titik bantu.
